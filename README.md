# PhotoArchiveCatalog v6.0.0

Windows photo archive catalog for the Archive of the President of the Kyrgyz Republic.

## GitHub build outputs

The workflow `.github/workflows/build-windows.yml` creates two downloadable artifacts:

- `PhotoArchiveCatalog_Setup_v6.0.0.exe` — full Inno Setup installer.
- `PhotoArchiveCatalog_Update_v6.0.0.zip` — update package for the in-app updater.

See `README_RU.txt` for the complete Russian description.
