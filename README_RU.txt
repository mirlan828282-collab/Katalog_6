PhotoArchiveCatalog v6.0.0
Фотокаталог — Архив Президента Кыргызской Республики

ЧТО НОВОГО В ЭТОЙ ВЕРСИИ

1. Готовый установщик через GitHub Actions + Inno Setup.
   GitHub создаёт:
   - PhotoArchiveCatalog_Setup_v6.0.0.exe — полный установщик.
   - PhotoArchiveCatalog_Update_v6.0.0.zip — пакет обновления.

2. Новый значок программы:
   золотая архивная папка «АРХИВ» с фотографиями людей.

3. Постоянное место хранения данных:
   Документы\PhotoArchiveCatalog\
      Database\catalog.db
      Photos\
      Backups\
      Settings\
      Updates\
      Logs\
      Cache\Thumbs\

   Удаление/обновление программы не должно удалять эти данные.
   При первом запуске новая версия пытается перенести старую базу Katalog_5
   из %LOCALAPPDATA%\PhotoArchiveCatalog_Katalog5.

4. Окно «Каталог»:
   - отдельная кнопка «Извлечь фото из Access»;
   - извлечение фотографий из поля Access типа «Вложение» (Attachment);
   - привязка по архивному номеру;
   - режим «только отсутствующие фото» для безопасного повторного импорта;
   - несколько вложений могут создавать дополнительные карточки;
   - прогресс и итоговая статистика;
   - заметная нумерация записей;
   - ползунок «Высота строки»;
   - описание переносится на несколько строк при увеличении высоты;
   - отдельный ползунок размера миниатюр;
   - настройки вида сохраняются.

5. Быстрое удаление:
   - выбранные записи удаляются пакетно одной транзакцией;
   - таблица обновляется один раз;
   - при большом удалении отображается прогресс;
   - можно удалить только записи или записи вместе с файлами;
   - файл не удаляется, если он всё ещё используется другой карточкой.

6. Настройки программы:
   - кнопка «⚙ Настройки» доступна сверху во всех окнах;
   - дневной/ночной режим;
   - фон, кнопки, выделение;
   - размер шрифта;
   - высота строк каталога;
   - размер миниатюр;
   - «Открыть папку архива»;
   - «Установить обновление из файла».

7. Обновление программы:
   - можно выбрать полный EXE-установщик;
   - можно выбрать ZIP-пакет обновления, созданный GitHub;
   - база данных и фотографии хранятся отдельно от Program Files.

ВАЖНО ДЛЯ ACCESS ATTACHMENT
Для извлечения вложений Access на Windows должен быть установлен
Microsoft Access Database Engine / DAO подходящей разрядности.
Если его нет, программа покажет понятное сообщение.

СБОРКА В GITHUB
Файл .github/workflows/build-windows.yml автоматически:
1) устанавливает Python и зависимости;
2) скачивает модели поиска лиц;
3) собирает PhotoArchiveCatalog.exe;
4) собирает PhotoArchiveCatalogUpdater.exe;
5) устанавливает Inno Setup;
6) создаёт установщик;
7) создаёт ZIP-пакет обновления;
8) загружает оба результата в Artifacts.
